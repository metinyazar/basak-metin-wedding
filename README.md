# Başak & Metin · Düğün Sitesi

4 Temmuz 2026 · 20:00 · Turkuaz Düğün Salonu, Söke

GitHub Pages ile yayınlanan statik düğün sitesi. Davetiye renk ve tasarımında.

## Daha sonra güncellenecek yerler

- **SoundCloud şarkıları** — `index.html` içinde iki `<iframe>` örnek parça içeriyor. Gerçek SoundCloud track linkleriyle değiştir.
- **Bağış** — `index.html` içinde `Dernek Adı`, `https://example.org` linki ve sertifika placeholder'ı var. Dernek bilgisi belli olunca güncelle.
- **Sertifika görseli** — `certificate.jpg` olarak ekleyip `index.html` içindeki yorumlu `<img>` satırını aç.

## Yerelde çalıştırma

```bash
python3 -m http.server 4173
# http://localhost:4173
```
